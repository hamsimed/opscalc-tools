    Formula

    Production rate = Units produced ÷ Operating timeAttainment = Production rate ÷ Target rateGap = Target rate × Operating time − Units produced
    Variables and units
    TermMeaningUnit
    Units producedOutput in the period (good units, or total — state which)units
    Operating timeTime the process was scheduled to runh
    Target ratePlanned or standard rateunits/h

    Worked example

    A filling line produced 900 cases in 6.5 scheduled hours. The standard rate is 150 cases per hour.

    Inputs
    Units produced900 units
    Operating time6.5 h
    Target rate (optional)150 units/h
    Results
    Production rate138.5 units/h
    Production rate2.308 units/min
    Target attainment92.3%
    Shortfall vs. target75 units

    Output is below target. Split the gap into stoppage time and slow running to see which loss dominates.

    Making the rate meaningful

    Define the time base before comparing rates. "Operating time" can mean scheduled time, run time or time excluding breaks. Each definition gives a different rate. For a shift report, scheduled time shows the whole loss. Run time isolates speed losses.

    When attainment is below 100%, split the gap into stoppage time (availability) and running below rate (performance). The OEE calculator does this split.

    Typical uses

    • Shift and daily production reports.
    • Checking a new standard rate against observed performance.
    • Estimating the hours needed to complete an order: units required ÷ observed rate.

    Rate vs. capacity planning

    To estimate how long an order will take, divide the quantity by the observed rate, not the nameplate rate. If you only have a design rate, multiply it by a realistic OEE or efficiency figure from your own history. In the example, a 1,500-case order at the observed 138 cases per hour needs about 10.8 scheduled hours, compared with 10 hours at standard rate.

    Common mistakes

    • Mixing scheduled time and run time between periods.
    • Counting total output in one report and good output in another.
    • Comparing rates across products with different work content.

    Where it’s used

    • Shift reports and daily production meetings.
    • Estimating hours to complete an order.
    • Validating standard rates.

    Questions

    Should I use good units or total units?

    Use good units if the rate feeds customer delivery planning. Use total units if you want to measure machine speed. Label the report clearly either way.
