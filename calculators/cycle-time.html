Cycle Time Calculator

Average cycle time is the observed time between completed units over a period. Use this calculator to turn production time and output into seconds per unit and units per hour, and to check the result against takt time.

Observed vs. ideal cycle time

The value here is an observed average: it already includes minor stops and slow cycles. It differs from the ideal cycle time used in OEE, which is the best achievable cycle. The gap between them is the speed and minor-stop loss.

For line balancing, time individual stations with a stopwatch or machine logs and record several cycles. Averages hide variation, and variation causes queues.

Using the result

  • If average cycle time is above takt, the process cannot meet demand in the available time.
  • If it is just below takt, small disruptions will cause missed output. Check the margin against your stop history.
  • Throughput (units/hour) is the same information in another form. Planners and supervisors often prefer it.

Measuring cycle time on the shop floor

  • Time at least 10 to 20 consecutive cycles, and note anything unusual (minor stops, waiting for material).
  • Record the lowest repeatable value as well as the average. The difference shows how much instability costs.
  • For manual work, separate operator cycle time from machine cycle time. The longer of the two sets the pace.

Frequently asked questions

Is cycle time the same as lead time?

No. Cycle time is the interval between completed units. Lead time is how long one unit takes to go through the whole process, including queues.

Should I include changeover time?

For the average cycle time of a run, include only running time. Track changeovers separately so you can reduce them with SMED.
